# ADR-0004: Só dados do próprio aluno

## Contexto e problema
LGPD; Guia de IA (p. 9 e 18).

## Decisão
Nenhuma tool expõe participantes, posts de colegas ou notas de terceiros.

## Opções consideradas
- **Escolhida:** a decisão acima
- Expor fóruns e participantes

## Consequências
- Bom: Elimina o tratamento de dados de terceiros.
- Ruim / a acompanhar: Fóruns de discussão entre alunos ficam fora.
