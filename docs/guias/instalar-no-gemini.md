# Instalar no Gemini CLI

> Guia (Diátaxis): passos para quem já sabe o que quer.

Pré-requisito: [uv](https://docs.astral.sh/uv/) instalado.

```bash
gemini extensions install https://github.com/kauantpereira/mes-moodle-mcp   # a validar
```

Na instalação, informe o endereço do Moodle e onde guardar os prazos ([opções](../referencia/configuracao.md)).
