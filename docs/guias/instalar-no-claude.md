# Instalar no Claude Code / Desktop

> Guia (Diátaxis): passos para quem já sabe o que quer.

Pré-requisito: [uv](https://docs.astral.sh/uv/) instalado.

```bash
/plugin marketplace add kauantpereira/mes-moodle-mcp
/plugin install moodle-mcp@mes-moodle-mcp
```

Na instalação, escolha onde guardar os prazos. O endereço do Moodle não é pedido: na UFMG vale o semestre atual; outro Moodle usa a variável `MOODLE_URL` ([configuração](../referencia/configuracao.md)).
