# Primeiros passos

> Tutorial (Diátaxis): uma experiência guiada, do zero ao primeiro resultado. A escrever quando as tools da história A existirem.

1. Instalar o plugin no seu agente.
2. Fazer login no Moodle (o navegador abre; o servidor nunca vê a sua senha).
3. Perguntar: "o que mudou nas minhas disciplinas esta semana?"
4. Escolher onde guardar os prazos (calendário, tarefas, arquivo .ics ou só o chat).
